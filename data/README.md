In our automatic image captioning project, we used the Flickr8K dataset, downloaded from Kaggle. It contains around 8,000 images, and each image has five captions written by humans to describe what is happening in the picture. The dataset includes different types of images, such as animals, people, nature, and daily activities. These images and their captions help our model learn how to understand the content of a picture and describe it in simple, meaningful words. This allows the model to generate captions automatically, making images easier to understand and more accessible to everyone.
