Abstract : Automatic image captioning combines deep learning, computer vision, and natural language processing (NLP) to generate meaningful descriptions of images. This study develops an image captioning system using the Flickr8K dataset, which contains approximately 8,000 images with five captions each. A CNN encoder extracts visual features, while an RNN decoder with an attention mechanism generates relevant captions word by word. The system targets to reduce manual image annotation, improve image accessibility for visually impaired individuals, and support efficient image retrieval. Caption quality can be reviewed using metrics such as BLEU, ROUGE-L, and METEOR.

Problem Statement: Understanding the content of images and describing it in meaningful sentences is a challenging task for computers. Manual image captioning is tedious, and they lack automatic descriptions which can create difficulties for visually impaired individuals and limit image accessibility.

Objective: The objective of this project is to develop an automatic image captioning system which will convert visual information into meaningful language using CNN for visual feature extraction, RNN for sequential caption generation, and a Transformer based self-attention mechanism to capture contextual relationships between image features and words. The system will generate meaningful appropriate captions that describe objects, their activities and interactions within an image. The performance of this system will be evaluated using word-level accuracy, precision, recall and f1-score, along with Bleu, Meteor, and Rouge-L metrics to assess caption quality. It aims to improve image accessibility for visually impaired people and also support applications such as automated image description and image retrieval.

Methodology Overview: 1.Dataset collection : Flickr8k dataset is used in this project., which contains images paired with human-written descriptions and it includes 5 captions per image. 2.Data Preprocessing : Prepare the images and captions for training by resizing and normalizing images for Inception V3 image classifier and remove unnecessary words or symbols from captions and convert words into numerical representations. 3.Feature Extraction : An encoder converts an image into numerical features that the next part of the model can understand. For that , we have used Inception V3, a pretrained CNN which is used for image classification and feature extraction. 4.Caption generation using RNN and Bahdanau Attention : A RNN decoder is used to generate captions one word at a time. The Bahdanau Attention mechanism helps in focusing on the most relevant image features while predicting each word. 5.Model Training : Model is trained using this dataset so that it learns to generate captions accurately. The dataset was divided into 80:20 ratio. 80% used for training the model and 20% percent used for validating the model and adjusting the model parameters accordingly. 6.Caption geeration and Evaluation : Test the trained model using new images and evaluate the genrated captions using BLEU, METEOR, ROUGE-L Scores , Word-level accuracy, Precision, Recall and F1-score.

Explanation of the architecture used: Images are given to the encoder which gradually transforms raw pixels into a more meaningful numerical representation. In image captioning, using Inception V3, a pre trained CNN model it can extract features from the image. Encoder outputs the hidden states and the decoder current hidden state are passed to the alignment layer
which will compute the alignment score . Tanh activation function is used to introduce non-linearity into the alignment layer, allowing the model to learn complex relationships. The alignment layer compares the decoder’s state with each image region features for calculating the alignment score. Alignment score tells the decoder on which part of encoder’s output it needs to pay attention. To convert the raw alignment score to normalized attention weights we need to apply softmax layer. Attention weights tells us how much importance each image region should receive. The attention weight and hidden states of encoder will be added together to produce context vector. The model combines image features, giving importance to region with higher weights. The decoder uses this visual context to generate the next word using embedding layer(RNN layer), the output from decoder at last time stamp and context vector will be used by decoder for generating the next word, so this is how Bahdanau self attention works and the caption is generated as an output for the given input image.

Evaluation Metrics: The project evaluates generated captions using the metrics implemented in the evaluation code, which include: BLEU-1, BLEU-2, BLEU-3, BLEU-4, METEOR, ROUGE-L, Word-level accuracy, precision, recall and F1-Score, Exact-match accuracy. Results: The model generates captions for input images and compares them with the human-written reference captions. The quantitative evaluation results are available in results/results.csv. Example visualizations and attention maps are available in results/figures/.

Limitations: 1.Limited Dataset Size : The Flickr8K dataset contains approximately 8,000 images, which is relatively small for training complex deep learning models. As a result, the model may not learn enough visual patterns to describe every type of image accurately. It may perform well on familiar scenes but struggle with unusual objects or situations. 2.Difficulty Understanding Context : The model may identify individual objects but fail to understand the complete situation. For example, it might recognize a person and a bicycle without correctly describing the person's activity or the relationship between them.

Future Scope: 1.Use Larger and More Diverse Datasets : Our future work can use larger datasets, such as Flickr30k or MS COCO, containing more images and captions. A more diverse dataset can help the model learn a wider range of objects, activities, backgrounds, and real-world situations. 2.Improve CNN-Based Feature Extraction : More advanced image encoders, such as EfficientNet, ResNet, or Vision Transformer (ViT), can be explored to extract richer visual features. Better feature extraction may help the model recognize objects and understand complex scenes more effectively.
